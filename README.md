# 공개용 가상 업무 시스템 시연

실제 사용 중인 업무 보조도구의 **화면 구조와 조작 방식**을 개인정보 없이 설명하기 위한 독립 시연 페이지입니다.

- 가상의 접수 신청 상세 화면을 열면 **화면 우측 하단에 독립적인 검토 보조 패널**이 나타납니다.
- 패널은 드래그로 이동하고 접을 수 있으며, 신청을 변경하면 표시 내용이 함께 변경됩니다.
- 지도와 근거문서는 별도 팝업으로 열립니다.
- 상단/좌측 메뉴에서 신청 목록, 관리센터, 구역 관리, 현황 대조 및 발급 보조로 이동합니다.

**모든 신청정보, 업체명, 주소, 필지, 통계는 허구이며 실제 운영시스템/API와 연결하지 않습니다.**
실제 업무 코드, 실제 고객정보, 기관명, 내부 도메인 및 인증 정보는 게시하지 않았습니다.

단일 페이지 `index.html`에 CSS/JavaScript를 모두 포함하므로 GitHub Pages에서 별도 빌드가 필요하지 않습니다.

이 데모 자체는 실제 3개월 사용 이력을 증명하는 자료가 아니라 기능 조작을 보여주는 시연본입니다.
